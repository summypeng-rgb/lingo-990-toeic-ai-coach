# Lingo 990 — TOEIC AI Coach

一個結合 TOEIC 模擬考場、AI 雙人聽力情境、口說面試與多輪英文對話的互動式學習 Prototype。

## 功能

- 學習 Dashboard 與弱點訓練建議
- Listening Part 3 AI 雙人情境對話
- 正式考試倒數、單次播放與題組作答流程
- AI 口說面試與麥克風錄音
- AI 自由對話、語音辨識與英文朗讀
- 發音、流暢度、文法及字彙分析
- 桌面與手機響應式介面

## 本機執行

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```
